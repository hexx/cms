# 静けさは視覚言語として輸入し、青は能動 UI だけに使う

参考元（しずかなインターネット）から輸入するのは雰囲気であり、情報設計そのものではない。配色は無彩色の階調を主役にし、`basicTheme.accent` の青は現在位置・フォーカスリング・主要操作に限定する。本文中のリンクは青くせず、本文色 + ドット下線で示す。色の付かないリンクは「スタイル漏れ」に見えるため、後から青リンクに“修正”されないよう記録する。あわせて、行間や余白のゆとり、`h2` の下罫線、引用の淡い箱は輸入するが、**一覧の説明文・タグ・種別は削らない**（＝参考元の「情報を削ぎ落とした静けさ」は採らない）。この判断は `docs/spec.md` §8.4 に原則として書く。
