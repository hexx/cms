# X へは自動配信せず、Web Intent による手動投稿にする

X の API は 2026年2月から完全従量課金になり、新規開発者に無料枠がない。URL 付き投稿は1件 $0.20（約30円）で、ブログの配信は常に URL 付きになるため、自動化すると記事ごとに課金が発生する。よって X への配信は自動化せず、記事ページに「X に投稿」ボタンを置き、定型文を入れた Web Intent（`https://x.com/intent/post`）を開く半自動方式にする。他の Destination はすべて API で自動配信する。

## Consequences

- X の OAuth 資格情報・トークン更新・従量課金の管理が不要になり、Syndicator の責務が減る
- X への投稿は手動操作の分だけ遅れる／忘れる可能性がある。忘れ防止は Discord への通知で代替する
- 将来 X を自動化したくなった場合は、Syndicator に Destination を1つ足すだけで済む（手動ボタンは併存可能）
